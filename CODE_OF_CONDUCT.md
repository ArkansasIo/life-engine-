# Code of Conduct

## Our standard

Participants in the LifeEngine project are expected to be respectful, constructive, and welcoming. Focus criticism on technical ideas and behavior, not personal characteristics.

Examples of expected behavior include:

- Using clear, considerate language.
- Explaining technical disagreements with evidence.
- Accepting good-faith corrections.
- Respecting different experience levels and backgrounds.

Unacceptable behavior includes harassment, threats, deliberate intimidation, personal attacks, and publishing another person's private information without permission.

## Maintainer response

Project maintainers may edit or remove unacceptable contributions and may restrict participation when necessary to protect the community. Reports should include relevant links and context and should be sent privately to the repository maintainer.

This policy applies to project issues, pull requests, discussions, and other spaces used for LifeEngine project work.

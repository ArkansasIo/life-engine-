Complexity from simple rules.

LifeEngine lets you inspect emergent behavior: local cell interactions can produce stable structures, oscillators, and expanding patterns. The browser build is designed as a static client, so the simulation runs locally on your device.

BIOLOGY MODULE

From cells to ecosystems.

The biosphere panel reads a JSON data source with biome and organism records. It is a starter integration point for richer taxonomy, climate, habitat, genome, and organism models from the desktop project.
